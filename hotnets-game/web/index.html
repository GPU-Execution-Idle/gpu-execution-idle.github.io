Wake the GPU!

How to read the game

Network prediction. Each purple bracket is the predicted arrival range for the next request: the previous arrival plus the middle 40% (30th–70th percentile) of the latest 16 gaps between requests seen on the network. The bracket starts one wake latency (0.32 s) plus half a second of reaction time before the earliest predicted arrival, so pressing when it starts (or up to half a second later) always wakes the GPU in time for a request that lands in the range. Only past arrivals are used; the range is a guide, not a guarantee.

Work. When a request arrives, a line rises from the start of its work into the prediction row, showing where it landed in the range. Dark blocks are the GPU processing it. After a late wake, the work still starts on arrival, but its first part (hatched amber) runs at reduced frequency, so it takes longer.

GPU frequency (the row you control). Low is idle, the slope is the wake-up ramp, high is ready or working. Red marks a premature wake: waiting at high frequency burns energy (labeled when it lasts long). Amber marks a late wake: the work runs at reduced frequency, which hurts latency. Gray marks the automatic drop back to low power after the work.

Timing. Wake latency is 0.32 s. Replay speed is adjusted: waits play in real time, while the wake-up ramp and the work are slowed so they are visible. Results use the original timings.

One press per wait. The game pauses once after the first request; press Space to continue.
